# ⛳ SidCup - Golf Website Clone

A smooth and stylish clone of [SidCup Golf](https://sidcup-golf-family.netlify.app/), built using HTML, CSS, and JavaScript.  
Focuses on stunning layout, hover effects, and 3D-like animations.

> ⚠️ Not fully responsive. Best viewed on desktop.
